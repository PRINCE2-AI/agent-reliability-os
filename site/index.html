How a call is stopped

1. Propose

The agent selects a tool call with arguments. Nothing has executed yet.

2. Decide

Deterministic rules score risk and return allow, approval, or block — plus redacted arguments and the matched rules.

3. Record

The decision, the trace, and the evaluation land in SQLite, so a run can be re-read instead of re-guessed.
